# CurseForge listing

## Summary
Choose which chat tab is selected when you log in, instead of always starting on General.

## Description
**Quick Chat** remembers which chat tab you want to start on. Made a tab for Guild, Trade or your group? Pick it once, and it's the tab you see every time you log in or reload, instead of General.

### Features
* Choose your default tab from a dropdown in the settings panel
* Works with any tab docked with General, including ones you created yourself
* Switches on login and `/reload` only, never on zone changes or loading screens
* Saved per character, since each character has its own chat tabs
* Lightweight, with no dependencies

### How it works
* The tab is remembered by name and position, so moving it around the dock doesn't lose it.
* If the tab is renamed, deleted or undocked, General is used and the settings panel shows a notice. Your choice is kept, so the tab is picked up again if it comes back.
* If you click another tab right after logging in, Quick Chat leaves it alone.
* Whisper and other temporary tabs aren't listed.

### Settings
Open Esc > Options > AddOns > Quick Chat, or type `/quickchat` or `/qchat`.

Choosing **General** turns the addon off, and the game behaves as usual.

### Other Quick addons
Part of the Quick family: Quick Questing, Quick Abandon and Quick Money Transfer.
